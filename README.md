An interactive, scroll-driven 3D storytelling portfolio built with **Three.js**, **GSAP**, **Lenis**, and **Vite**. The experience takes visitors on a real-time narrative journey through my path as a software developer and AI engineer—from foundational schooling, to riding a bicycle across campus at R.V.S. College of Engineering & Technology, to architecting full-stack microservices and agentic AI systems at my developer studio desk.

---

## ⚡ Key Highlights

- **Kinematic 3D Character & Bicycle Rigs**: Fully articulated, non-robotic designer 3D character with synchronized walking strides, bicycle pedaling, and desktop coding animations driven by scroll distance.
- **120fps Inertial Scroll Choreography**: Built with [Lenis](https://github.com/darkroomengineering/lenis) and [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/) for smooth camera rail moves and narrative chapter triggers.
- **Architectural 3D Environment**: Travertine pathways, schoolhouse landmarks, college glass-facade wings, and an illuminated studio desk with animated real-time code and telemetry monitors.
- **Editorial Typography & Runtime Font Switcher**: Set in **Syne** (Awwwards display), **Space Grotesk** (systems engineering sans), and **Instrument Serif**, featuring an interactive 1-click header switcher (*Syne*, *Bricolage Grotesque*, *Space Grotesk*) saved to `localStorage`.
- **Palette**: High-contrast **Midnight Black** (`#09090b`), **Pure White** (`#ffffff`), and **Lime Green** (`#a3e635`).
- **Direct Live Links**: Instant access to live demos and GitHub repositories for all flagship projects.

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/Vishxlll20/3d-portfolio.git

# 2. Navigate to project root
cd 3d-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
